# Yard Boss: Level Up

Phone-first single-file web app for Nick's gamified savings system.

## What is included
- Locked envelope progression
- XP requirements
- Daily missions
- Perfect Day bonus
- Boss Coins
- Luck stat
- Mystery loot that only reveals after bonus XP
- Achievements
- Skill stats
- Auto-save using localStorage
- GitHub Pages ready

## Deploy
Upload `index.html` and `README.md` to the root of a GitHub repository.
Then enable GitHub Pages from Settings > Pages > Deploy from branch > main > root.
