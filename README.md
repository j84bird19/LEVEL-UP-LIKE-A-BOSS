# Nick's Yard Boss Level-Up

Single-file phone-friendly web app.

## How to use
Open `index.html` in a browser, or upload it to GitHub Pages / Netlify.

## Systems included
- Locked envelope levels
- XP requirements
- Bonus XP mystery rewards
- Daily task XP
- Auto-save with localStorage
- Achievements
- Boss Coins and Fun/Gamble wallet
